# 论文复现边界

论文访问权限取决于开放获取状态和用户所在机构的订阅，不由“本科生、研究生、博士生或教授”等身份名称决定。

## 允许的输入

- 用户合法持有并主动提供的论文；
- 出版商开放获取全文；
- arXiv、PMC、机构知识库等合法公开来源；
- 用户本人已登录且有权使用的图书馆或数据库页面。

## 禁止的行为

- 保存或索取机构密码、Cookie、验证码和会话令牌；
- 绕过付费墙、DRM、频率限制或身份认证；
- 将受版权限制的论文全文随开源代码重新发布；
- 把论文缺失的几何、材料和边界参数当成事实自动补齐。

## 后续阶段建议

论文复现应先生成“参数证据表”，逐项记录参数值、单位、论文页码或图表来源。缺失参数必须标记为待确认，并允许用户选择敏感性分析范围。第一阶段尚未实现论文下载和自动参数提取。
