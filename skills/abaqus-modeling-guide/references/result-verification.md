# 仿真结果如何核查

区分三个层次：程序运行完成；离散模型求解可信；模型能够描述真实问题。求解成功或出现云图只能说明部分流程完成，不能证明工程结论正确。纯结果审查读取现有证据，不自动提交新作业。

## 按证据逐层判断

1. **作业证据**：核对配置、作业名、运行目录、时间和求解状态；读取日志与实际 ODB，避免拿旧结果或未完成分析的最后一帧当本次最终结果。
2. **模型定义**：检查一致单位制、材料来源、平面应力/应变或三维假设、厚度、加载方向和约束。查看变形趋势是否与约束和载荷一致。
3. **理论数量级**：使用适用假设一致的解析解或已验证基准。矩形板小变形单轴拉伸可用 `epsilon=delta/L`、`sigma=E*delta/L` 检查远离边界的名义轴向应力。默认值对应约 210 MPa；这是理论估计，不是运行结果。
4. **平衡与输出定义**：有数据时核对外力与反力、力矩等；动力问题考虑惯性和阻尼，不能照搬静力平衡。明确积分点、节点平均值、分量和模的差别。
5. **离散敏感性**：对关注量进行网格细化；动力分析还需检查时间增量。建议至少三档作趋势判断，保持同一取值定义。误差容限由任务/规范/用户确定，不把固定百分比当通用标准。
6. **物理验证**：对照实验、可靠文献或独立基准，说明材料标定与验证数据是否独立、误差及适用范围。无外部证据就标为“尚未完成物理验证”。

## 不超出当前提取器能力

先读取当前版本提取代码和 `results.json` 的真实字段。当前基础报告主要给最大位移模和最大 Mises 应力；没有 S11、竖向 U2、反力 RF、接触输出或能量时明确标为“未提取”。不得把 Mises 峰值当截面平均轴向应力，也不得把位移模直接称为梁端竖向挠度。

所需量缺失时提出具体输出需求：变量、区域、分析步、帧/时间序列、取值位置、单位。若现有 ODB 已有数据，可在用户要求的结果审查范围内只读提取；若 ODB 未保存该量，则说明需修改输出请求并重新求解，获得覆盖该工作的授权后执行。

## 常见误判

- 固定端、点载荷、尖角附近峰值可能随网格细化继续增大；先判断奇异性，不机械追求全模型峰值收敛。
- 接触问题检查开闭状态、压力、滑移和传力；具体输出变量需核对求解器/版本是否支持及是否已请求。
- 界面损伤、塑性和大变形问题不能使用线弹性比例关系证明正确。
- 能量比值、人工能量等指标只有实际输出后才讨论，限值必须有适用依据。

给出简短核查表：检查项、证据文件/数值、结论（通过/不通过/未检查）、下一步。保留失败和缺失项，不只展示支持结论的数据。收敛验证与实验验证分开报告。
