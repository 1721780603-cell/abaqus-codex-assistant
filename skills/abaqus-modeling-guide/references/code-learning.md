# 用实际代码学习建模

目标是让学习者能指出参数在哪里、修改会改变什么物理关系、结果如何检查。纯代码讲解不启动 Abaqus。

## 选取真实代码

先确定用户选择的模型，读取其配置、调用入口和实际建模脚本。通过项目搜索定位，不猜文件名、行号或 API。优先采用用户提供的脚本；仅有 EXE 且没有源码时，明确缺少源码，可解释已有配置或给出标注为“示意、未执行”的片段，不能声称它就是安装版内部实现。

按实际程序梳理：配置读取 → 草图/零件 → 材料与截面 → 装配 → 分析步 → 约束与载荷 → 网格 → Job → ODB 提取。无需一次讲完；从用户关心的块开始，每次选择一个物理动作，给出约 5–20 行原代码、来源文件及行号。

每块连接四件事：

1. Python 在做什么：变量、函数、对象、循环或字典；只讲当前片段所需概念。
2. Abaqus 在创建什么对象，对应哪个 GUI 模块。
3. 参数的物理含义、单位、来自哪个真实 JSON 字段。
4. 改变它会有什么预期，以及运行后检查哪个量。

区分 JSON 配置、普通项目 Python 和 Abaqus 内置 Python。`mdb`、`session` 等对象需要相应 Abaqus 环境，不能让用户把建模脚本当普通 Python 程序随意运行。API 名称和版本差异以当前代码及对应版本官方文档为准。

## 入门练习

优先从矩形板的 `right_edge_displacement` 入手：定位右侧边界的位移设置，解释位移与应变、应力的联系。让用户预测将 0.1 mm 改为 0.2 mm 后的变化，再按参数实验资料设计验证。

引导用户用一句话解释：这个参数控制什么、固定了哪些条件、要看哪个输出。答错时回到对应代码和物理关系，不通过堆砌更多代码纠正。

只有用户请求修改时才编辑实际文件；使用个人配置，保留基准案例。讲解结束明确区分“已阅读”“已修改”“已运行”，未运行不报告数值结果。当前执行器不支持的几何、接触或材料可讲原理与阅读代码，但不能把示意代码作为已验证执行能力。
